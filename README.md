# Agrovila São Luiz
Frontend demonstrativo de uma plataforma web desenvolvida para a Agrovila São Luiz, com foco na divulgação de produtos, cursos, notícias e informações da comunidade.

## Sobre o projeto
O projeto foi desenvolvido com o objetivo de criar uma interface moderna, responsiva e acessível para apresentar conteúdos relacionados à agricultura familiar, cursos e iniciativas da comunidade.
Esta versão disponível no GitHub contém apenas o frontend da aplicação para fins de demonstração e portfólio.

## Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript
- Bootstrap

## Funcionalidades do frontend
- Página inicial responsiva
- Área administrativa visual - removida para esta versão
- Exibição de produtos
- Página de notícias
- Página de cursos
- Navegação responsiva
- Interface moderna e intuitiva

## Observações
O sistema original foi desenvolvido utilizando PHP e MySQL no backend.  
Nesta versão pública do projeto:

- O backend foi removido;
- O banco de dados não está incluído;
- Funcionalidades dinâmicas estão representadas de forma estática;
- O projeto foi adaptado para hospedagem no GitHub Pages.

## Objetivo acadêmico
Projeto desenvolvido durante participação em bolsa acadêmica no IFAL, voltado para aplicação prática de desenvolvimento web.
